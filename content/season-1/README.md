# Season 1 — Agent Awakening(原理觉醒)

> 用故事与比喻讲透 AI Agent 的核心机制。第一季优先制作文字内容,视频属于后续可选扩展。

## 定位

- 通过游戏化闯关、故事、生活比喻与技术图解,理解 AI Agent 从底层原理到上层应用的核心机制。
- 重点是理解核心概念、形成准确的技术直觉,不是工程实现(工程路线在 [Season 2](../../docs/roadmap.md))。
- 每篇都是适合公开分享的原创技术内容。

## 发布形式

| 渠道 | 形式 | 文件 |
|---|---|---|
| 微信公众号 | 完整中文技术文章 | `article.md`(正文确定后创建) |
| 朋友圈 | 简短学习心得 | `moments.md` |
| X | 英文 Thread | `x-thread.md` |

当前只创建提纲(各集目录下的 README),**正文确定后再按需增加上述文件**,不提前批量生成。

## 统一叙事结构

每篇遵循:

```text
有趣的问题 → 生动的故事 → 真实的技术原理 → 一个具体例子 → Boss 挑战 → 一句话总结
```

## 每篇质量清单

1. 一个核心知识点
2. 一个容易记住的生活比喻
3. 一张清晰的原理图(必要时)
4. 技术概念与比喻之间有明确映射
5. 解释比喻的局限,避免技术误导
6. 一个能引起思考的挑战问题(Boss)
7. 一句适合复习的技术口诀
8. 自然引出下一关

## 写作风格

- 生动、有故事感;面向具备基本计算机知识的开发者
- 专业但不堆砌术语;不故意夸大 Agent 能力
- 以公开学习和探索的视角展开
- 不将尚未完成的工程实验描述为已完成
- 只谈技术知识、学习心得、工程实践与开源协作
