# Learning Notes — 学习笔记

> Personal Mastery 的载体。每关的原理理解、代码摘录、运行记录、故障分析都写在这里。
> AI 可以替你写代码，但**不能替你写笔记**——笔记是你掌握程度的证据。

## 使用方式

每通关一关，复制下面的模板追加一节。写完才算完成该关的 Personal Mastery 部分。

## 模板

```markdown
## Level N — <关卡名>（日期）

### 原理理解
- 用自己的话解释本关核心机制（不抄任务书）

### 关键代码
- 最关键的 20–50 行在哪里（文件:行号），为什么是它

### 运行记录
- Demo 命令与真实输出（粘贴关键片段）
- 测试结果（pytest 输出摘要）

### 故障分析（Boss 战）
- 制造了什么故障、观察到了什么、根因是什么、怎么修的

### 独立修改
- 不借助 AI 完成的一个小改动（描述 + 提交链接）

### 下一步
- 想深入的问题、可改进的设计
```
