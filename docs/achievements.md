## 成就等级（每关独立评定）

| 等级 | 要求 |
|---|---|
| 🛡️ **Builder** | 工程通关：Demo 成功 + 自动化测试通过 + Boss 战通过 + Git 提交 |
| 🛠️ **Engineer** | Builder + 个人掌握：能讲清执行链路、指出关键 20–50 行、独立修改功能、预测并验证故障 |
| 👑 **Master** | Engineer + 额外高难度挑战（在关卡任务书中定义或自行提出） |

## 发放规则

1. 以**证据**为准：测试输出、运行记录、Git 提交链接。
2. 工程通关由自动化测试客观判定；个人掌握由学习笔记与独立修改的代码判定。
3. AI 生成的代码可以帮助工程通关，但**不能**替你获得 Engineer / Master。
4. 每次解锁在本文件与 [progress.md](progress.md) 同步登记，注明证据位置。
