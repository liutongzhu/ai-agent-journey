## 双层通关机制

### Engineering Clear（工程通关）

- Demo 成功运行。
- 自动化测试通过。
- Boss 故障测试通过。
- Git 提交完成。

### Personal Mastery（个人掌握）

- 能解释关键执行链路。
- 能指出最重要的 20–50 行代码。
- 能独立修改一个小功能。
- 能预测并验证一次故障行为。

两者独立记录。**Claude Code 生成的代码不等于学习者已掌握。**

## XP 发放纪律

- XP 只根据**真实证据**发放：可复现的运行输出、通过的测试、Git 提交。
- 文档已创建 ≠ 能力已解锁。
- 不提前发放 XP，不提前创建 Tag。
